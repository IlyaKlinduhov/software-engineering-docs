# Окружение разработки

Для разработки нужны Python 3.10 или новее, Git и браузер. Поддерживаются Windows, Linux и macOS. Проект использует только стандартную библиотеку Python.

CI выполняется с Python 3.12 на облачном runner GitHub. Собственный Windows runner проверяется отдельным ручным workflow. Результат сборки — статические файлы каталога в `dist`.

История просмотров сохраняется в браузере. Сервер SQL, внешние API и платные ресурсы для учебного примера не нужны.
