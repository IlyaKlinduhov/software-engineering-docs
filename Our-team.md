# Команда StudyFlow

Владелец учебного проекта — IlyaKlinduhov. Работа разделена на плановые направления StudyFlow Web и External integrations. Они показывают согласование графиков двух команд без создания фиктивных пользователей.

Изменения документации сохраняются коммитами. Основной процесс: описать задачу и критерии приёмки, назначить спринт и оценку, выполнить проверку, затем принять результат.

Этот файл получен переименованием первоначального README и дополнен описанием команды. История Git сохраняет обе операции.
