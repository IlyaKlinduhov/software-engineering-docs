# Начало работы

Получите репозиторий `IlyaKlinduhov/software-engineering-practices`, затем выполните:

```text
python -m unittest -v
python build.py
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Каталог поддерживает поиск, выбор темы и сохранение недавно просмотренных материалов.

Для просмотра готовой версии установка не нужна: [опубликованное приложение](https://ilyaklinduhov.github.io/software-engineering-practices/).
